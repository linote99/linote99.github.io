# 网关打磨记：MU300 SIP 网关 0.3.0 的坑与解法

## 这一轮改了什么

0.2.20 之后，网关进入了「每天用、随手提需求」的打磨期。这一轮的改动单看都不大：网页电话拨号盘上删号码的 ⌫ 按钮挪进按键行、按一张参考图 1:1 复刻了图标；语音信箱的提示音从一声孤零零的「滴」换成真人语音「滴声后请留言」，中英男女四种音色在设置里自选，留言录音特意等提示音播完才开始，不吞留言的第一个字；再加上 Linphone 上线时网页电话自动关闭、网页电话页一键「下线 Linphone」（通话结束或空闲若干分钟后自动恢复，分钟数可设）、状态页一键「结束当前通话」、状态页显示网关开关……

功能都不复杂。真正花时间的，是下面这几个坑——它们没有一个出在新功能本身，全出在「平台的默认行为」和「协议里只发一次的消息」上。

## 坑一：设置里关掉的网关，关不掉

在设置页把网关总开关关掉，Linphone 照样注册、电话照样打——开关像个摆设。

查到最后发现，问题不在开关，在「关」这个动作的存法：LuCI 的开关控件关闭时不是写入 `0`，而是**把这一项配置整个删掉**；而守护程序读不到这一项时，按默认值处理——默认就是开。于是「关」这个操作永远落不了地。更麻烦的是，这不是总开关一个人的毛病：所有「默认开启」的开关（自动关闭网页电话、短信、通话记录……）全都带着同一个隐患，只是还没人去关它们。

修法有两层：让这些开关关闭时强制写下 `0`（LuCI 侧 `rmempty=false` 并给默认值）；再在启动脚本里加一道闸——配置说关，进程就不许起。双保险之后实测：关掉，进程归零；打开，服务回来。顺手在状态页加了一行「网关开关：已开启/已关闭」，守护程序停着的时候也能一眼看出开关状态。

## 坑二：同一条短信，响个没完

短信桥出过一阵「短信风暴」：同一条短信被反复投递，聊天里刷屏，日志也被冲得飞快。两个诱因叠在一起：

一是**重试没有上限**。转发给 Linphone 只要没拿到确认，网关就把这条标回「未读」，下一轮再发——对方一直确认不了，就永远发下去。

二是更隐蔽的：有人在 Linphone 里回复短信时，正文里混进了看不见的 NUL 字节。网关把正文交给发送命令时，程序因为这个字节直接崩溃，接口返回 500——Linphone 以为没发成功，于是它也开始无限重试。两边都在「负责地重试」，合起来就是一场风暴。

修法：同一条短信最多重试 3 次，超了就认了；发送前把正文里的 NUL 字节清掉。日志里从此清净。

## 坑三：电话在打了，Linphone 却说「拨打中」，还挂不掉

这是这一轮最典型的一个。用 Linphone 拨号，电话其实已经接通、在计费了，Linphone 界面却一直停在「拨打中」；点挂断没反应，最后只能跑到网页电话里才能挂掉。

根子是 SIP 的一个老规矩：被叫接通后，网关回一个 200 OK，手机必须回一个 ACK 确认，这个「对话」才算正式成立。问题是这张 200 OK 走的是 UDP，**只发了一次**。这一发但凡没到位，手机端就永远停在「未正式接通」的状态：它显示拨打中，它能发的挂断信号只有 CANCEL；而网关的代码里，CANCEL 只处理「还没接通」的通话——「已经接通」的直接忽略。于是死局成型：手机挂不掉，网关不理睬，只有网页电话内部的挂断能拆。

修法照着协议本来的设计补：200 OK 按退避节奏（0.5 秒起、翻倍、32 秒封顶）**重发到收到 ACK 为止**，重发内容必须与首发逐字一致（应答里的时间戳变一个字，对方就当成新会话）；同时放行一种 CANCEL——已接通但还没收到 ACK 的外呼，允许用 CANCEL 拆掉。修完实测一通电话：ACK 准时到达、双向语音、最后 BYE 干净收尾。

## 坑四（假坑）：「已注册」与「未注册」对不上

新做的「下线 Linphone」上线后，出现过一幕灵异事件：点下线、再点恢复，打开 Linphone 显示「已注册」，网关后台却显示「未注册」，而电话偏偏还能正常打。

差点当成 bug 修。先抓现行：盯着网关日志，让手机把账号关掉再打开——REGISTER 立刻进来，后台秒变「已注册」。真相是：下线期间 Linphone 的注册被拒绝后，它进入了长时间的退避重试，恢复之后迟迟没有再发注册请求，界面上挂着的还是旧状态；网关这边没有注册绑定，如实显示「未注册」。至于电话能打——外呼靠的是账号密码的摘要认证，和注册状态本来就没关系，注册只管来电往哪儿送。

教训是通用的：**两边状态对不上时，先看报文，别先改代码。**

## 结尾

这一轮的坑排下来有个共同点：出事的都不是「功能没写对」，而是默认值（读不到就当开）、一次性（一发定生死）和没上限（重试到天荒地老）。把这三处补齐，0.3.0 打包完成，统一包同时适配两台内核不同的 MU300，装上按 `uname -r` 自动选驱动集。

下一轮？等哪天用着不顺手再说。
