# Lino-UFI工具：用安卓手机一键安装 UFI-TOOLS

我把 UFI-TOOLS 电脑版「一键安装器 1.9.2」（Windows）的流程移植到了 Android，做成了 **Lino-UFI工具**。手机本身就是 ADB 主机：连上随身 WiFi 的热点，点一下按钮，就能完成开启 ADB、安装、授权、保活设置、启动和重启设备，不需要电脑。

[UFI-TOOLS](https://github.com/kanoqwq/UFI-TOOLS) 本体（包名 `com.minikano.f50_sms`）由 **MiniKano** 开发并开源，是一款免费工具，严禁倒卖。本应用只是其电脑版一键安装器的安卓移植，不包含 UFI-TOOLS 本体。

## 一键安装

使用前先让手机连上随身 WiFi 的热点，然后点击「开始一键安装UFI-TOOLS」。App 会按电脑版的命令和顺序依次完成：

1. 获取 UFI-TOOLS 安装包；
2. 查找 ADB 设备：先找 USB OTG，再试无线 ADB（`192.168.0.1:5555`）；都找不到时，用安装器内置的默认后台密码登录设备网页后台（`192.168.0.1:8080`）开启 ADB，再等待 ADB 出现；
3. 安装或更新 UFI-TOOLS，授予短信、存储、电话和通知权限，设置使用情况访问、通知监听、电池白名单，关闭休眠和自动撤销权限；
4. 启动 UFI-TOOLS 并确认它已在运行，15 秒后自动重启设备。

设备重启后，用浏览器打开 `http://192.168.0.1:2333` 即可使用 UFI-TOOLS。自动重启和电脑版行为一致，也可以在主页面关掉。如果只想打开 ADB、不安装任何东西，点「仅开启 ADB」即可；自动开启失败时，还可以点「后台 USB 设置」到设备网页里手动打开。

安装过程中，系统可能弹出 USB 访问授权，设备也可能弹出调试授权，点允许即可。开启 ADB 后，随身 WiFi 的 USB 会重新枚举，可能需要再允许一次。

## 两种连接方式

**无线 ADB** 不需要接线，手机和随身 WiFi 在同一热点下就行。热点提示「无互联网」时保持连接即可：App 会把访问设备的流量绑定到 Wi-Fi，同时开着移动数据也能访问 `192.168.0.1`。

**USB OTG** 适合无线 ADB 不通的情况，比如部分固件开启 ADB 后只提供 USB 调试。手机需要支持 USB 主机模式，用 OTG 转接头或 OTG 数据线把随身 WiFi 接到手机，此时随身 WiFi 由手机供电，耗电会稍快。

目前只支持经典的 5555 无线 ADB 和 USB 调试，不支持 Android 11 及以上的「无线调试」配对端口（TLS）。

## 安装包从哪里来

安装包有三种来源：与电脑版相同的在线下载源（取最新版）、自定义下载链接，或手机上的本地 APK 文件。为避免装错东西，App 额外做了几项检查：

- 下载内容必须是 ZIP/APK，并逐项校验压缩包，避免把错误网页当成安装包；
- 日志里显示安装包的 SHA-256，可以和发布页核对；
- 包名不是 `com.minikano.f50_sms` 时先询问；
- 自定义链接是 HTTP（非 HTTPS）时先提醒。

默认设置（设备地址 `192.168.0.1`、后台端口 `8080`、电脑版内置的后台密码、在线最新版安装包）适用于大多数设备，可以直接安装。需要修改时，**在主页面连续点击标题「Lino-UFI工具」5 次**，会打开单独的「高级设置」页面，里面有设备设置（地址、后台端口、后台密码、一键安装的 ADB 连接方式）和安装包设置，返回即自动保存。

## ADB 工具：投屏、备份与恢复

主页面的「ADB 工具」卡片提供三项功能。它们使用卡片右上角「⚙ 设置」里单独的设备 IP 和 ADB 端口（默认 `192.168.0.1:5555`，也可改用 USB OTG），直接连接设备的 ADB，不登录后台，也不需要后台密码。前提是设备已经开启 ADB，没开时可以先点「仅开启 ADB」。

**ADB 投屏**可以在手机上查看并操作随身 WiFi 的屏幕。流畅模式使用打包进 APK 的开源项目 [scrcpy](https://github.com/Genymobile/scrcpy) 5.0.1 设备端组件（未修改，Apache-2.0），H.264 实时画面，支持单指点按、滑动和多指操作，底部有返回、主页和多任务键，右上角可以切换「流畅 / 标准 / 高清」三档画质。投屏不传输声音。设备不支持硬件编码或流畅模式启动失败时，会自动改用截图模式（循环刷新截图），速度较慢但兼容性更好，也可以手动切换。

**备份安装包**会列出设备上用户安装的应用，勾选后通过 ADB 拉取安装包，保存到你选择的手机文件夹：单个 APK 存为 `.apk`，拆分安装的应用存为 `.apks`。注意这里只备份安装包本身，不包含应用数据和设置。

**恢复安装包**可以多选 `.apk` / `.apks` 文件，通过 ADB 重新安装到设备，允许覆盖安装和降级。

## 使用前请注意

- 系统版本过高时，官方禁用了 ADB，需要先降级：F50 需在 B15 以下，U30 亚太版需在 B19 以下，U30 普通版需在 B25 以下，V50 需在 B21 以下。这一点和电脑版一样无法绕过。
- 安装过程中不要拔线、断开热点或手动重启设备。
- 只安装可信来源的安装包。
- 提示签名不一致而安装失败时，先在设备上卸载旧版 UFI-TOOLS 再安装。
- 电脑上的 adb 等其他程序占用设备 ADB 时可能连接失败，请先断开它们。

应用右上角的「ⓘ」打开关于页，里面有完整的使用说明、连接方式和注意事项。
