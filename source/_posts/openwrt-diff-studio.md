# OpenWrt Diff Studio 安卓版：在手机上生成差异包并更新设备

我把桌面版的 **OpenWrt Diff Studio**（含 Patch Updater）移植到了 Android。它做两件事：比较两版 OpenWrt 发行包，生成只包含变更文件的差异包；再通过 SSH 把差异包应用到正在运行 OpenWrt 的设备上。配置、额外插件和用户数据会保留，不需要每次都刷完整固件。

应用分为两个页签：「生成差异包」和「更新设备」。切到更新页时，顶部标题会显示为 **OpenWrt Updater**。当前版本 1.1.0 同步了 2026-10-26 的电脑版（电脑版现已分为 E5 系列版和 MU300 版两个包）。

## 生成差异包

在「生成差异包」页选择旧版（设备当前运行的版本）和新版完整 ZIP 发行包。目前支持 E5（ext4 根文件系统），以及 MU300 / F50 / V50 / U30Air（tar 根文件系统）。旧版既可以是完整 ZIP，也可以是之前保存的版本摘要，详见下一节。

点击「分析差异」后，应用会显示目标设备、内核、版本变化、变更文件清单和载荷大小；如果不能生成差异包，会列出具体原因。文件清单在手机上最多显示前 4000 项。

确认无误后，可以点击「导出差异包」保存完整更新包 ZIP，里面包含 `update.ota`、电脑端更新器和说明；也可以点击「仅导出 .ota 文件」。导出的补丁与电脑版格式相同，同样可以用电脑端更新器，或在设备网页「系统 > 系统补丁」中导入。

## 新功能：版本摘要

以前每次生成差异包，都得把旧版完整 ZIP 一直留着。1.1.0 新增了 **版本摘要**（`.owrt-index.json`）：每次分析成功后，应用会自动保存新版的摘要。下次生成差异包时，旧版直接选这个摘要即可，不必再保留旧版完整包；新版仍然需要选择完整 ZIP。

摘要只记录文件清单、软件包版本和校验值，不含任何系统文件内容。被篡改或格式不正确的摘要会被拒绝。

在应用里，旧版的文件选择器可以选 ZIP 或摘要 JSON。分析完成后可以点「导出版本摘要」把它保存出来，给电脑版使用；「已保存的版本摘要」列表里可以把某个摘要用作旧版、导出或删除。

用摘要生成的差异包，可能会比用完整包生成的少几个文件。这些是更新器自身的程序文件，摘要里已有记录，属于正常情况。另外要注意，保存了摘要并不代表设备已经更新；用作旧版的摘要必须对应设备当前运行的版本。

## 通过 SSH 更新设备

在「更新设备」页选择 `.ota` 差异包，也可以在文件管理器里直接用本应用打开 `.ota`。然后填写设备管理地址和 root 密码：E5 默认是 `192.168.9.1`，MU300 默认是 `192.168.77.1`，也支持写成 `地址:端口`。

更新分两步进行。先点击「连接并检查」，应用会检查剩余空间、本地修改、依赖冲突和版本是否匹配；全部通过后，再点击「确认应用此补丁」。检查与应用之间会核对设备身份，中途换了设备或设备被重置，就需要重新检查。

1.1.0 起，设备端更新改为在后台启动。更新过程中，App 会自动轮询并显示当前阶段：准备文件、准备更新、正在更新。也可以随时点击「重新检查设备状态」。可以勾选「更新完成后自动重启」，也可以在完成后手动点击重启；如果写入失败，设备会用写入前保留的恢复副本自动回滚，并在界面上提示结果。

这一版还同步了电脑版新增的两条错误提示：「检查结果不完整」和「上传内容不一致」，出现问题时更容易看出卡在哪一步。另外，E5 和 MU300 现在各自使用对应电脑版的设备端引擎；E5 的受保护路径从 `/etc/e5-nvbackup` 改为 `/etc/e5-nv`。

## 手机上的几处适配

手机连上提示「无互联网」的路由器 Wi-Fi 时，Android 往往会把流量转到移动数据。本应用会自动选择能到达设备地址的网络（Wi-Fi、USB 网络共享或以太网）建立 SSH 连接，所以保持连接即可。

分析、导出和设备写入期间，应用会启动前台服务并显示通知，切到后台或锁屏也不会被系统中断。设备端的更新事务是独立运行的，即使关掉 App，也不会中断设备上的写入。

界面支持中英文切换和深浅色主题。应用内的「关于」页附有完整的使用步骤和注意事项，1.1.0 也补充了版本摘要的用法。

## 使用前请注意

- 只导入和应用可信来源的补丁，补丁会以 root 权限写入系统文件。
- 旧版（完整包或版本摘要）必须与设备当前运行的版本一致；检查未通过时不要强行更新。
- 更新期间保持设备通电，不要拔电或手动重启。
- 设备虽然会在失败时自动回滚，重要配置仍建议先在设备网页里备份。
- 分析 E5 发行包需要临时解压根文件系统镜像，手机需要预留足够空间（通常几百 MB 以上）。
- 保存时如果文件名显示被截短，直接保存即可，导出完成后会自动恢复完整文件名和扩展名。

## 安装

应用包名为 `com.linote.diffstudio`，需要 Android 8.0 及以上。安装包使用自签名证书，需要允许从此来源安装；1.1.0 与之前各版本签名相同，可以直接覆盖升级。

第一次给设备装 OpenWrt，可以用另一个工具：[OpenWrt 安装器（安卓版）](/posts/openwrt-android-installer/)。
